## Décision

Le seul statut `PARTIAL` concerne l’emplacement UX du choix de structure initiale : le modèle collège est choisi dans New Exam, la duplication est disponible depuis le Dashboard, mais il n’existe pas de bouton explicite « structure vide ». Cela ne bloque ni un workflow professeur ni une exigence documentaire, et est classé **MINOR**.

Il ne reste aucun BLOCKER ni MAJOR V1 démontré. Décision : **READY FOR V1 RELEASE**.
